RUSTLINE is a round-based tactical FPS in three.js: Vanguard vs Sentinel on the Foundry Yard map, first to 5 rounds, plant/defuse objectives, a buy-phase economy, 5 weapons plus grenade and vest, and bots with waypoint pathfinding.

## Run it

```sh
node serve.ts
```
